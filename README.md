# Harran Link 成品下载

只放**可直接运行的成品**的公开仓库：不含源码、不含构建脚本、不收集任何本机信息。
源码与开发记录在同账号的私有仓库里，这里只负责把唯一一个文件交到你手上。

## 下载

进入 [Releases](https://github.com/wyx2781617228-lab/Harran-Link-Releases/releases) 选择最新版本，下载 `Harran-Link-<版本>-win-x64.exe`。

当前版本 **0.7.0**：

| 文件 | 大小（字节） | SHA-256 |
|---|---|---|
| `Harran-Link-0.7.0-win-x64.exe` | 183,123,937 | `ec35fd8492b801013c4d8046c209d5da7a7586e7d67e38a28daf2f9f14e2c834` |

下载后请核对哈希（PowerShell）：

```powershell
Get-FileHash .\Harran-Link-0.7.0-win-x64.exe -Algorithm SHA256
```

## 这是什么

面向 Windows 10 / 11 x64 的私人局域网联机框架：EasyTier 建立虚拟网、房间邀请码、游戏发现与启动、按游戏挂载的端口修复与 MOD 同步。免安装，双击即可运行；只有真正组网时才需要按提示以管理员身份重启。

第一个适配游戏是《消逝的光芒 1》1.55，另含《土豆兄弟》与通用局域网游戏入口。

## 0.7.0 带来的变化

- **学习版 / 绿色版可用了**：没有任何商店记录时，在「游戏与检查 → 本机游戏 → 添加游戏目录」指定装游戏的那层文件夹，程序只在所选目录内有界扫描（最多 32 个目录、4 层深度、4,000 个子目录，跳过软链接与回收站），下次启动继续生效。
- **基础游戏版本指纹改成随程序分发的数据表**：不再把某一渠道的构建写死在代码里；新渠道加一档是指纹数据，不是代码改动。
- **指纹表里没有的本机构建，给一条明确的确认安装路径**：勾选「允许未登记的本机基础版本」后，按本机实测基线备份再安装，还原沿用同一条记录。这个勾选只放开文件写入边界，**不代表这个构建能和 Steam / Epic 版本互相加入**。
- **游戏包按组件增量装配**：修改器改版只重下变化的那一个组件（2.8 MB 而不是 12.3 MB），同一版本重复装配是 0 字节；每个组件都先校验 SHA-256 才落盘。

## 使用前必须知道的三件事

1. **未代码签名。** 程序里没有签名证书，Windows 可能提示「未知发布者」；这是预期行为，不是被篡改。请以上面的 SHA-256 作为唯一真伪依据。
2. **双方必须是同一版本、同一游戏构建。** 版本号同为 1.55 不足以保证能互相加入；工具的「校验全部文件」只证明文件一致，不证明联机通过。
3. **这个成品尚未完成双机实机验收。** 见下面「未验证」清单，请把它当测试版而不是发布版来用。

## 已验证

- 202 个离线单元与 IPC 测试全部通过（文件写入边界、备份与还原、清单校验、权限与路径校验）。
- 真实便携 EXE 的只读冒烟测试通过：界面启动、内容包入口、预设 API 与状态检查，不启动游戏、不组网、不写游戏文件。
- 虚拟网卡就绪、共享节点连接、回环核心互相发现；独立测试进程内的 `sendto` / `WSASendTo`（含重叠 I/O）目标端口 `0 → 20101` 修正、目标过滤与停止恢复。
- 游戏包增量装配：缓存命中时 0 字节传输，装配后清单、固定摘要与磁盘内容三者一致，校验不过整体退回原状。
- 内容包安装事务：先备份全部同名文件再覆盖，失败回滚本轮写入并保留原有备份，还原只在手动触发时发生。

## 未验证

- Steam 版、Epic 版、学习版三种构建之间的**双机互相加入与游戏内 LAN 对局**。
- 修改器在游戏内的实际表现（手电筒、枪械伤害等）在非本机 gamedll 构建上的有效性。
- 《土豆兄弟》内置加载器的实际游戏加载与双机兼容。
- 完整内容包（1,058 个文件）在其他机器上的真实安装结果。

## 隐私

- 程序不上传本机路径、账号、游戏目录、存档或任何标识信息；所有网络请求只用于组网与按公开哈希下载内容包。
- 内容包组件通过不带凭据的 HTTPS 获取，资产哈希在仓库内公开可核。
- 诊断导出默认剔除邀请码与密钥。
- 设置、缓存与备份只写在 `%APPDATA%\Harran Link`，删除该目录即可清干净；游戏目录里的改动有独立备份，只能手动还原。
